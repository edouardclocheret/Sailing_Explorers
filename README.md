# Sailing explorers

Controls: 

- Use the space bar to move forward, and left and right arrow to rotate the boat.
- Use I and O to zoom in and out.

After tweaking UI buttons, make sure to click again on the game window to reactivate the controls!

Note: if when launching the game, the boat is on land, it won't be able to move. Just relaunch, and a new map will be generated!
